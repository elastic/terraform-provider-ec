# Resource: ec_elasticsearch_project



## Example Usage

### Basic

```terraform
resource "ec_elasticsearch_project" "my_project" {
  name      = "my_project"
  region_id = "aws-us-east-1"
}
```

### With audit logging

```terraform
# The destination must be an existing observability or security project.
resource "ec_observability_project" "audit_logs" {
  name      = "my_audit_logs"
  region_id = "aws-us-east-1"
}

resource "ec_elasticsearch_project" "my_project" {
  name      = "my_project"
  region_id = "aws-us-east-1"

  monitoring = {
    logging = {
      audit = {
        # enabled defaults to true. Set it to false to pause delivery while
        # keeping the configuration.
        destination = {
          project_id   = ec_observability_project.audit_logs.id
          project_type = "observability"
        }
        # Optional. Ids of logging ignore filters that drop matching audit
        # events before delivery.
        ignore_filter_ids = ["audit-ignore-data-reads"]
      }
    }
  }
}
```

Audit logs are delivered to a serverless project of type `observability` or `security`. `destination.status` is read-only and reports whether that project is accepting logs. Set `enabled = false` to pause delivery while keeping the configuration. The predefined `ignore_filter_ids` are listed in the [Elastic Cloud Serverless API reference](https://www.elastic.co/docs/api/doc/elastic-cloud-serverless/operation/operation-listignorefilters).

~> **Note on audit logging** Audit logging configured outside Terraform is removed on the next apply unless the configuration includes `monitoring.logging.audit`.

## Import

Projects can be imported using the `id`, for example:

```shell
terraform import ec_elasticsearch_project.id 320b7b540dfc967a7a649c18e2fce4ed
```

~> **Note on Credentials** The `credentials` attribute (containing `username` and `password`) is only available when the project is first created. When importing an existing project, these credentials will not be available in the Terraform state as the API does not return them on read operations.
